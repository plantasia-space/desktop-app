# Plantasia Space for desktop

Downloads of the [Plantasia Space](https://plantasia.space) desktop app, *Home for Regenerative Music*: worlds, orbiters and your music in their own window, with `plantasia-space://` links that open straight in the app.

## Download

Get the latest version from [Releases](https://github.com/plantasia-space/desktop-app/releases), or from [plantasia.space](https://plantasia.space):

| System | File |
| --- | --- |
| macOS, Apple Silicon | `Plantasia-Space-mac-arm64.dmg` |
| Windows, x64 | `Plantasia-Space-win-x64-setup.exe` |
| Windows, Arm | `Plantasia-Space-win-arm64-setup.exe` |

### First launch

The app is not yet signed by Apple or Microsoft, so the first open asks for your OK:

- **macOS** — open the app once, then go to **System Settings → Privacy & Security** and choose **Open Anyway**.
- **Windows** — if SmartScreen appears, choose **More info → Run anyway**.

To update, download the latest release again.
